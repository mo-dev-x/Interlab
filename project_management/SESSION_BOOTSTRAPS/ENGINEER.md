# Persistent Engineer Bootstrap

Use this conversation for successive bounded implementation work orders. Do not reconstruct project
history in chat.

At each handoff:

1. Read `project_management/PROJECT_STATE.md`.
2. Read only the active work item in `project_management/CURRENT_PLAN.md`.
3. Read the referenced blueprint/ED sections, not the full decision history.
4. Preserve user-owned changes and all explicitly excluded paths.
5. Implement only the bounded scope, run the required evidence, and report deltas plus hidden
   consequences. Do not commit unless asked.

The current item is identified by the Orchestrator's routing block; do not
infer it from this bootstrap.
